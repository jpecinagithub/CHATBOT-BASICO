# Chatbot mínimo

El chatbot más sencillo posible construido con Vite, React y Puter.js.

## Puesta en marcha

No necesitas configurar credenciales. Instala y arranca el proyecto:

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`. La primera vez que envíes un mensaje, Puter puede mostrar una ventana para iniciar sesión.

El flujo completo es: escribir una pregunta, llamar al modelo y mostrar su respuesta.
